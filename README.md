# Smart Pantry Manager

## Project Overview
Smart Pantry Manager is an Android application developed using Java and SQLite. It helps users manage pantry items, track quantities, record expiry dates, and find recipes based on the ingredients available.

## Features
- Add pantry items with a name, quantity, category, unit, and optional expiry date.
- View saved pantry items.
- Update item quantities.
- Delete pantry items.
- Suggest recipes based on available ingredients and quantities.
- View recipe preparation instructions.
- Access the Settings/Profile screen.
- Store pantry data locally using SQLite.

## Technologies Used
- Java
- Android Studio
- SQLite
- Android SDK
- Git and GitHub

## Database
SQLite is used to store pantry information locally on the device. This allows pantry records to remain available when the application is closed and reopened.

## How to Open the Project
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download any required dependencies.
4. Run the application on an Android emulator or compatible Android device.
